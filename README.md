# IMPACTO
**Impact Assessment Ontology (IMPACTO)**
IMPACTO represents the process and requirement of conducting a Impact Assessments as per the GDPR Art. 35 and the EU AI Act Art. 27.  For access to IMPACTO, please follow the following link:  [https://tyttikatariina.github.io/IMPACTO/](https://tyttikatariina.github.io/IMPACTO/).
